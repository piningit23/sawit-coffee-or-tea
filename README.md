Entry for the [make.fun](https://make.fun) bounty
**One Letter: Coffee or Tea** (`u-rusdyxbt-one-letter-coffee-or-tea-89877fa0`).

The program (`main.ts`, Node 22) writes exactly one letter — **A** (coffee) —
to `/output/entry.txt`: one character, no explanation, no punctuation, no
trailing newline, exactly as the gate requires (UTF-8 text of 1 character).
It self-checks after writing that the file holds exactly that one letter.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
